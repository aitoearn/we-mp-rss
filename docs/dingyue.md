# 订阅与 RSS 使用说明

本文说明如何在 WeRSS 桌面版中添加公众号订阅，并获取 RSS 链接供阅读器使用。

## 前置条件

1. 已安装并启动 WeRSS 桌面应用（见 [desktop-app.md](./desktop-app.md)）
2. 使用默认账号 `admin` / `admin@123` 登录（首次登录后建议修改密码）
3. 在「微信状态」页面完成扫码授权

## 添加订阅

1. 进入「订阅管理」
2. 点击「添加订阅」
3. 按提示搜索或粘贴公众号信息并保存
4. 等待定时任务采集，或在订阅列表中手动触发更新

采集完成后，文章会出现在「文章列表」，同时生成对应 RSS 地址。

## 获取 RSS 链接

在「订阅管理」中选中公众号，复制 RSS 链接。格式一般为：

```
http://127.0.0.1:{端口}/feed/{公众号ID}
```

桌面版后端默认监听本机端口（通常 `8001`）。若需在局域网其他设备访问 RSS，需在 `config.yaml` 中配置 `rss.base_url` 并确保防火墙放行。

## 配合 RSS 阅读器

推荐使用 [Folo](https://github.com/RSSNext/Folo) 等 RSS 客户端订阅上述链接，即可在阅读器中同步公众号更新。

## 常见问题

**扫码授权失败或过期**

进入「微信状态」重新扫码。授权过期时应用会通过配置的通知渠道提醒（若已配置 Webhook）。

**订阅后没有新文章**

- 确认定时任务已启用（`config.yaml` 中 `enable_job: true`）
- 在「消息任务」中检查调度是否正常
- 手动触发一次采集

**RSS 全文不完整**

在 `config.yaml` 中确认 `rss.full_context` 为 `true`，并等待文章内容采集完成（部分文章需二次补全正文）。
