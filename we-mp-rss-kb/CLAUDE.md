# WeRSS LLM-Wiki Schema

> 写给 LLM 的工作规范。你是本知识库的全职编辑，负责持续维护、交叉引用与一致性。

## 角色

- **你**：Wiki 维护者（可读可写 L2 层）
- **人**：只读消费者，通过 Obsidian 或 Cursor 查询
- **L1 源**：`../docs/`、`..` 代码仓、用户提供的材料（只读，不可修改）

## 三层架构

| 层 | 名称 | 规则 |
|----|------|------|
| L1 | Sources | 原始文档/代码，LLM 只读不写 |
| L2 | Wiki | 本 vault 全部 markdown，LLM 全权维护 |
| L3 | Schema | 本文件 + `KB-META.md`，指导工作流程 |

## 核心操作

### Ingest（摄入）

触发：用户提供新文档、代码变更、或指定 `../docs/` 下文件。

流程：
1. 读取 L1 源材料
2. 提取关键实体、概念、模块关系
3. 在 `sources/` 创建或更新摘要页
4. 逐一更新受影响的 `entities/`、`concepts/`、`code/` 页面
5. 补充双向链接 `[[页面名]]`
6. 更新 `index.md`
7. 在 `log.md` 追加操作记录

**原则**：一次摄入触达多个页面；摘要写结论，细节链到实体/模块页。

### Query（查询）

触发：用户提问。

流程：
1. 从 `index.md` 和目录结构定位相关页面
2. 综合 Wiki 内容回答
3. 若答案有长期价值 → 写入 `queries/YYYY-MM-DD-{主题}.md`
4. 若发现 Wiki 缺口 → 标注 `[待补充]` 并建议 Ingest

**原则**：好答案写回 Wiki，不消失在聊天历史。

### Lint（巡检）

触发：用户要求巡检，或 ≥10 页变更后。

检查项：
- [ ] 矛盾：不同页面描述是否冲突（代码仓优先于 Wiki）
- [ ] 孤页：无 inbound 链接的页面
- [ ] 死链：引用 `[[页面]]` 但目标不存在
- [ ] 缺失：被提及但未独立成页的概念/实体
- [ ] 过时：代码已变更但 Wiki 未更新
- [ ] Frontmatter：type/created/updated 是否齐全

输出：问题清单 + 建议修复动作，修复后更新 `log.md`。

## 页面模板

### 概念页（concepts/）

```markdown
---
type: concept
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
---

# 概念名称

## 概述
核心描述（2-3 句）。

## 核心功能
- [[子概念]]：说明

## 相关模块
- [[模块名]] — 说明

## 关键实体
- [[实体名]] — 说明

## 相关文档
- [[文档摘要名]]

## 注意事项
- 关键边界与风险
```

### 实体页（entities/）

```markdown
---
type: entity
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
---

# 实体名

## 存储
表名 / 文件路径

## 字段
| 字段 | 类型 | 说明 |

## 关系
- 关联 [[其他实体]]

## 相关 API
- 接口路径与用途

## 注意事项
```

### 模块页（code/modules/）

```markdown
---
type: module
created: YYYY-MM-DD
updated: YYYY-MM-DD
module: 模块名
tags: []
---

# 模块名

## 职责
一句话描述。

## 目录结构
关键文件列表。

## 核心类/函数
| 名称 | 职责 |

## 依赖关系
- 依赖 → [[模块]]
- 被 → [[模块]] 调用

## 相关概念
- [[概念]]
```

## 命名与链接

- 文件名用中文或英文，与标题一致
- 跨页引用统一用 Obsidian 双向链接：`[[页面名]]`
- 代码路径用反引号，不用链接
- 日期格式：`YYYY-MM-DD`

## 禁止事项

- ❌ 修改 L1 源（docs/、代码仓）
- ❌ 编造不存在的类/字段/接口（不确定则标 `[待补充]`）
- ❌ 创建无 Frontmatter 的页面
- ❌ 大量复制粘贴原始文档（应写摘要 + 链接）

## 日志格式（log.md）

```markdown
## YYYY-MM-DD HH:MM — {操作类型}

- **操作**：Ingest / Query / Lint / 手动修复
- **触发**：用户请求 / 代码变更 / 定时巡检
- **变更页面**：[[页面1]]、[[页面2]]
- **摘要**：一句话说明做了什么
```
