# 定时任务调度

## 概述

WeRSS 的后台调度系统，负责定期采集公众号文章、执行 MessageTask、发送 WebHook 通知。

## 调度引擎

| 组件 | 路径 | 说明 |
|------|------|------|
| 主调度 | `jobs/mps.py` | 按 interval 采集各 Feed |
| 任务调度器 | `core/task/` | TaskScheduler 封装 |
| 任务队列 | `core/queue/` | 可视化队列管理 |
| 启动入口 | `main.py` | `-job True` + `server.enable_job=True` |

## MessageTask

用户可配置的消息任务：触发采集并将结果 POST 到外部 WebHook URL。

| 能力 | 说明 |
|------|------|
| 按公众号触发 | 绑定特定 Feed |
| 自定义 Headers/Cookies | 支持需认证的 WebHook |
| 测试模式 | 不实际发送，仅验证 |
| 执行日志 | MessageTaskLog 记录 |

## WebHook 投递

- 实现：`jobs/webhook.py`
- 内容格式：`webhook.content_format`（html/text/markdown）

## 通知任务

- 授权过期提醒、二维码通知
- 实现：`core/notice/`、`jobs/notice.py`
- 渠道：钉钉、飞书、微信、自定义 WebHook

## 注意事项

- 采集间隔：`interval` 配置（1-60 秒）
- 线程数：`server.threads`（默认 1，不建议超过 4）
- 级联模式下任务由父节点分发到子节点
