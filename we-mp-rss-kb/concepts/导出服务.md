# 导出服务

## 概述

将 [[Article]] 导出为 md/docx/pdf/json 等格式，支持批量导出与导出历史记录。

## 核心实现

| 组件 | 路径 | 职责 |
|------|------|------|
| 导出 API | `apis/export.py` | 导出请求与状态 |
| 导出工具 | `tools/mdtools/export.py` | 格式转换逻辑 |
| 导出历史 | `core/export_history.py` | JSON 文件型记录 |
| 前端组件 | `web_ui/src/components/ExportModal.vue` | 导出 UI |

## 支持格式

- Markdown (.md)
- Word (.docx)
- PDF (.pdf)
- JSON (.json)

## 导出历史

- 存储路径：`data/export_history.json`（非 DB 表）
- Web UI：`/export/records` 页面查看

## Electron 桌面版

- 支持本地目录选择导出
- 类型定义：`web_ui/src/types/electron.d.ts`
- 工具函数：`web_ui/src/utils/exportDir.ts`

## 相关模块

- [[apis模块]]
- [[web_ui模块]]

## 关键实体

- [[Article]] — `is_export` 标记是否已导出

## 注意事项

- 导出依赖 `has_content=1` 的正文
- PDF 导出依赖 docx2pdf / reportlab
- 桌面版通过 Electron IPC 选择导出目录
