# 级联系统文档摘要

## 来源

`docs/CASCADE_README.md` — WeRSS 级联系统完整实现文档。

## 核心能力

- 父子节点数据同步
- 级联 AK/SK 认证
- **智能任务分发**（按节点空闲情况自动分配）
- 子节点任务执行与结果上报
- 节点管理和监控
- 同步日志记录

## 架构组件

| 层 | 文件 | 职责 |
|----|------|------|
| 模型 | `core/models/cascade_node.py` | 节点与同步日志 |
| 管理 | `core/cascade.py` | 级联管理器和客户端 |
| 认证 | `core/auth.py` | 级联节点认证增强 |
| API | `apis/cascade.py` | 管理接口 |
| 同步 | `jobs/cascade_sync.py` | 子节点 Pull 服务 |
| 分发 | `jobs/cascade_task_dispatcher.py` | 任务分发器 |

## 数据模型

### CascadeNode

- `node_type`：0=父节点，1=子节点
- `api_key/api_secret`：级联认证凭证
- `parent_id`：父节点 ID
- `sync_config`：容量、配额等

### CascadeSyncLog

- `operation`：操作类型
- `direction`：pull / push
- `status`：同步状态
- `data_count`：数据条数

## 认证优先级

```
级联节点 AK/SK → 用户 AK/SK → JWT Token
```

## 父节点职责

- 管理子节点、生成凭证
- 提供数据接口（公众号、任务）
- 接收任务执行结果
- 查看同步日志

## 子节点职责

- 从父节点 Pull 数据
- 执行 MessageTask
- 上报结果、定期心跳
