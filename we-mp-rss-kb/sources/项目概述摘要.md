# 项目概述摘要

## 项目定位

WeRSS（we-mp-rss）是一个**微信公众号订阅助手**，用于抓取和管理公众号内容，生成 RSS 订阅源。

## 核心功能

- 微信公众号内容抓取和解析
- RSS 订阅生成（RSS/Atom/JSON/MD/TXT）
- Web 管理界面（Vue 3）
- 定时自动更新
- 多数据库支持（SQLite 默认 / MySQL / PostgreSQL）
- 多种抓取方式（web / app / api）
- 导出 md/docx/pdf/json
- API / WebHook 调用
- HTML 内容过滤规则
- 13 种主题切换
- **级联系统**：父子节点架构，智能任务分发
- **环境异常统计**
- **Headers/Cookies 认证**（MessageTask WebHook）
- **配置缓存**（Redis / Memcached / 内存）

## 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Python 3.13+、FastAPI、SQLAlchemy 2 |
| 前端 | Vue 3、Vite 8、TypeScript |
| 浏览器自动化 | Playwright |
| 数据库 | SQLite（默认）、MySQL、PostgreSQL |
| 缓存 | Redis |
| 桌面 | Electron 39 |
| 部署 | Docker、docker-compose |

## 架构

前后端分离：Python FastAPI 后端 + Vue 3 前端 + SQLite/MySQL 数据库。

## 快速启动

```bash
# Docker
docker run -d --name we-mp-rss -p 8001:8001 -v ./data:/app/data ghcr.io/rachelos/we-mp-rss:latest

# 本地开发
pip install -r requirements.txt
cp config.example.yaml config.yaml
python main.py -job True -init True
```
